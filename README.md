# App Usage Data Visualization

A radial data visualization built with Processing to explore and represent daily application usage data from CSV datasets.

## Preview

Project preview coming soon.

## Features

- Loads application usage data from CSV files
- Visualizes daily app usage in a radial layout
- Maps usage duration to graphical dimensions
- Dynamically positions visual elements using polar coordinates
- Generates colors for different applications
- Displays date labels and visual legends
- Transforms raw usage data into an interpretable visual format

## Project Overview

This project explores how application usage data can be transformed into a visual representation using Processing.

Usage data is loaded from CSV datasets and mapped to graphical elements arranged around a circular interface. The project uses mathematical calculations and coordinate transformations to determine the position and size of visual elements.

## Technical Concepts

The project demonstrates:

- CSV data parsing and transformation
- Data-driven graphics
- 2D visualization
- Polar coordinates
- Trigonometric calculations
- Loops and conditional logic
- Functions and data structures
- Visual encoding of quantitative data

## Running the Project

1. Install Processing.
2. Clone or download this repository.
3. Open `CC_project.pde` in Processing.
4. Ensure the required CSV files remain in their expected locations.
5. Click the Run button in Processing.
